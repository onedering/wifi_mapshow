Приложение предлагает открыть карту и открыть JSON файл. 
После этого карта и точки расставляются как в исходном приложении сканере. 

Далее внизу
Выбираем диапазон каналов - выпадающий список 
2.4 ( 1-13) 
5 (34-180) 
6 (14-33) 
6 (>180) 


И выпадающий список, в котором 
1) перечислены все ssid (все Bssid) 
2)Перечислены ssid(Bssid) 
Выбирается только одно значение в каждом. 
Далее нажимается кнопка показать. 
После этого в каждой точке определяется сеть, соответствующая условиям (фильтрам) , с максимальным уровнем. 
Точка отображается кружочком несколько пикселей, цвет выбран в соответствии присланной шкалой. 
Также рядом с точкой подписывается значение, которое программа выбрала (в скобках указать весь набор значений) 

Потом пользователь может изменить значения фильтров и показать повторно.
